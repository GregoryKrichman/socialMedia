
# MySocialProject - Frontend

## Description
MySocialProject is a social media platform where users can interact, share posts, and connect with friends. This is the frontend part of the project, built using React.

## Features
- User Authentication: Secure login and registration system to protect user data.
- Post Creation and Deletion: Users can create new posts and delete their own posts.
- Image Uploads: Easily upload and share images with your posts.
- Comments: Engage with posts by adding comments.
- Likes: Show appreciation for posts by liking them.
- Relationships: Follow other users and see their updates in your feed.
- Stories: Share short-lived content that disappears after 24 hours.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/GregoryKrichman/socialMedia.git
   cd mysocialproject-frontend
Install the dependencies:

npm install
Running the Application
Start the development server:


npm start
The application will open in your default web browser at http://localhost:3000.

Usage
Login/Register: Use the login or register page to create a new account or log in with existing credentials.
Home: View and interact with posts from other users.
Profile: View and edit your profile information.
Post: Create new posts and interact with existing ones.
Stories: View and share stories.
